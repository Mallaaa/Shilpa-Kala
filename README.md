# Shilpa-Kala

Shilpa-Kala is an Android application developed to help artisans such as wood carvers and Gombe makers improve the presentation of their handmade products. The app helps users capture professional-looking product photos, add branding elements, and share them easily on social media platforms.

## Features

- Product image capture using CameraX
- Guided camera overlay for proper product positioning
- Add “Handmade in Karnataka” branding
- Add product name, wood type, price, and artisan name
- Background enhancement options
- Save branded images to gallery
- Share images via WhatsApp and other apps
- Modern UI using Jetpack Compose

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- CameraX
- Bitmap & Canvas API
- MediaStore API

## Project Status

The project is currently under development. Basic UI screens and workflow are completed. Camera integration, image branding, and sharing features are in progress.

## Objective

The main objective of Shilpa-Kala is to support artisans by improving the visual presentation of handmade products and increasing their digital reach.
